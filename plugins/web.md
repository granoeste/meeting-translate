# web: Web 画面と OBS の字幕

`plugins/web.py` は、手元の Mac で小さな Web サーバーを動かし、翻訳を Web 画面と OBS の字幕に出します。既定で有効なので、何もしなくても起動します。

| 画面 | URL |
|---|---|
| Web 画面(話者別のログ) | `http://127.0.0.1:8765/` |
| OBS の字幕 | `http://127.0.0.1:8765/caption`(ブラウザソースに指定する) |

Web サーバーは 127.0.0.1 だけで待ち受けます。ネットワーク上のほかの端末からは見えません。会場の参加者に見せるときは [relay](../relay/README.md) を使います。

## OBS の字幕

背景は透過で、最新の字幕を下部中央に出します。ブラウザソースの大きさは 1920 × 1080 程度を推奨します。

URL パラメータで、表示を変えられます。

| パラメータ | 説明 |
|---|---|
| `?hold=5` | 字幕を出しておく秒数(既定は 8 秒) |
| `?orig=0` | 原文を隠して、訳文だけを出す |

## 設定(`plugins/web.toml`)

| 項目 | 既定値 | 説明 |
|---|---|---|
| `port` | `8765` | Web 画面と OBS の字幕のポート |

- `plugins/web.toml` は最初から置いてあります。ポートを変えるときは、`port` の行を書き換えます。
- 待ち受けるアドレス(127.0.0.1)は変えられません。

## 起動しないようにする

`plugins.toml` を作り、`plugins` から `"web"` を外します(例: `plugins = []`)。

```
cp plugins.example.toml plugins.toml
```
